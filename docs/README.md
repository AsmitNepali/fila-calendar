# Filament Calendar Docs

Documentation site for [asmit/fila-calendar](https://github.com/AsmitNepali/fila-calendar), built with the [Nuxt UI docs template](https://github.com/nuxt-ui-templates/docs).

## Development

```bash
cd docs
npm install
npm run dev
```

## Build (GitHub Pages)

```bash
NUXT_APP_BASE_URL=/fila-calendar/ npm run build
```

Output is written to `.output/public`.
